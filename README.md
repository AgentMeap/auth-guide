# Hướng dẫn tích hợp module bảo mật tài khoản (PRM393 - Courtly)

Trang tĩnh một file (`index.html`), không cần build. Hai đường: Spring Boot + SQL Server, hoặc Firebase trực tiếp.

## Bật GitHub Pages
1. Tạo repo mới trên GitHub, đẩy thư mục này lên nhánh `main`.
2. Settings -> Pages -> Source: Deploy from a branch -> `main` / `/ (root)` -> Save.
3. Sau 1-2 phút trang có tại `https://<tên-github>.github.io/<tên-repo>/`.
